## 📋 技能概述

这是一个自动化发布微信公众号文章的技能，支持：
- ✅ 自动转换 Mermaid 流程图为本地图表
- ✅ 使用 AI（通义千问）智能分析文章，自动生成封面提示词
- ✅ 使用通义万相、智谱 GLM-Image 或 Unsplash 生成封面图片
- ✅ 自动添加 Frontmatter 并发布到微信草稿箱
- ✅ 支持多种主题样式（orangeheart、green、blue 等）

## 🗂️ 文件结构

```
Article/Life/生活中的经济学/
├── .env                              # 配置文件（API Keys、主题等）
├── scripts/
│   ├── publish-enhanced.js          # 增强版发布脚本（核心）
│   ├── analyze_article.py           # AI 内容分析脚本（使用通义千问）
│   ├── generate_cover.py            # 通义万相封面生成脚本（Python SDK）
│   └── convert-charts.js            # Mermaid 转图表脚本（可选）
├── articles/
│   ├── images/                      # 生成的图表图片
│   ├── published/                   # 已发布文章存档
│   └── 01-机会成本与选择-经济学原理.md
└── README.md
```

## 🚀 快速使用

### 1. 前置依赖

```bash
# 安装 Node.js 依赖
npm install

# 安装 Python 依赖
pip install dashscope
```

### 2. 配置环境变量

在 `.env` 文件中配置：

```env
# ========================
# 微信公众号配置
# ========================
WECHAT_APP_ID=wx071b095c78095bc4
WECHAT_APP_SECRET=0e560908dcd91d9cddcc3b0ec0cf722c

# ========================
# AI 生图服务配置（推荐使用通义万相）
# ========================
# 通义万相（推荐，无水印）
AI_PROVIDER=wanxiang
WANXIANG_API_KEY=sk-xxxxxx

# 智谱 GLM-Image（备选，有水印）
# AI_PROVIDER=zhipu
# ZHIPU_API_KEY=xxxxxx

# Unsplash（备用，免费）
# AI_PROVIDER=unsplash

# ========================
# 发布主题配置
# ========================
THEME=orangeheart  # 可选: orangeheart, green, blue, red, purple 等
```

### 3. 发布文章

```bash
# 发布第 06 篇文章（使用默认主题）
node scripts/publish-enhanced.js 06

# 发布第 01 篇文章，指定主题
node scripts/publish-enhanced.js 01 orangeheart

# 预览模式（不实际发布）
node scripts/publish-enhanced.js 01 --dry-run
```

### 4. 高级选项

```bash
# 查看帮助
node scripts/publish-enhanced.js --help

# 使用智谱生成封面
AI_PROVIDER=zhipu node scripts/publish-enhanced.js 01

# 使用 Unsplash 免费图库
AI_PROVIDER=unsplash node scripts/publish-enhanced.js 01
```

## 📖 工作流程

```
1. 读取文章 → 提取标题和内容
   ↓
2. 转换 Mermaid → 下载图表到 images/ 目录
   ↓
3. 移除正文标题 → Frontmatter 已包含标题
   ↓
4. 调用 analyze_article.py → 通义千问分析文章内容
   ↓
5. 生成封面提示词 → 传递给 generate_cover.py
   ↓
6. 调用通义万相 → 生成封面图片
   ↓
7. 添加 Frontmatter → 保存到 published/ 目录
   ↓
8. 调用 wenyan CLI → 发布到微信草稿箱
```

## 🎨 主题配置

### 支持的主题

脚本内置按文章编号配置的主题，例如：

| 文章编号 | 主题关键词 | 封面描述 |
|---------|----------|---------|
| 01 | 十字路口、决策 | 职场人在十字路口做选择 |
| 02 | 递减、效率 | 打工人深夜办公场景 |
| 03 | 庆祝、团队 | 团队庆祝成功时刻 |
| 04 | 止损、陷阱 | 决策止损场景 |

### 自定义主题

编辑 `scripts/publish-enhanced.js` 中的 `THEME_KEYWORDS` 变量：

```javascript
const THEME_KEYWORDS = {
  '01': {
    name: '机会成本封面',
    color: '#E64A19',
    keywords: ['机会成本', '选择'],
    prompt: 'Professional business person standing at crossroads...',
    unsplashQuery: 'choice decision crossroad'
  },
  // ... 其他主题
};
```

## 🔧 技术栈

### 1. Node.js 脚本

- **publish-enhanced.js**: 主发布脚本
  - 功能：流程控制、图表转换、封面生成、微信发布
  - 依赖：fs、path、child_process、https

- **convert-charts.js** (可选): 独立的图表转换脚本

### 2. Python 脚本

- **analyze_article.py**: AI 内容分析
  - 使用通义千问 qwen-plus 模型
  - 提取文章核心视觉元素
  - 生成英文提示词

- **generate_cover.py**: 通义万相封面生成
  - 使用 dashscope SDK
  - 调用 qwen-image-plus 模型
  - 无水印，支持自定义尺寸

### 3. 外部服务

| 服务 | 用途 | 配置项 |
|-----|-----|--------|
| 通义千问 | AI 内容分析 | WANXIANG_API_KEY |
| 通义万相 | 封面生成 | WANXIANG_API_KEY |
| 智谱 GLM-Image | 备用封面生成 | ZHIPU_API_KEY |
| Unsplash | 免费图库备用 | 无需配置 |
| kroki.io | Mermaid 转图片 | 无需配置 |
| 文颜 CLI | 微信发布 | WECHAT_APP_ID/SECRET |

## ⚠️ 常见问题

### 1. 通义万相 403 错误

**错误信息**: `current user api does not support synchronous calls`

**原因**: 账户未开通同步调用权限

**解决**: 使用 Python SDK（已在 `generate_cover.py` 中实现）

### 2. AI 分析失败

**错误信息**: `dashscope SDK not installed` 或 `API call failed`

**解决**:
```bash
pip install dashscope
# 或检查 WANXIANG_API_KEY 配置
```

### 3. 微信发布失败

**错误信息**: `AppID/AppSecret invalid`

**解决**:
- 检查 `.env` 中的 `WECHAT_APP_ID` 和 `WECHAT_APP_SECRET`
- 确认已安装文颜 CLI: `npm install -g @wenyanlang/cli`

### 4. 图表无法显示

**原因**: 文颜 CLI 不支持 kroki.io 的 HEAD 请求

**解决**: 脚本已自动下载图表到本地 `images/` 目录
