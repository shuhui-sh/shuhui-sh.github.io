## 一、文章结构规范

```
┌────────────────────────────────────┐
│ 1. 引入案例（生活场景/真实故事）   │
├────────────────────────────────────┤
│ 2. 核心概念讲解                    │
│    · 概念定义 + 简单理解           │
│    · Mermaid图表（可选）           │
│    · 关键要点/对比表格             │
│    · 为什么重要/容易被忽视         │
│    · 相关概念对比（如需要）         │
│    · 历史小知识（可选）            │
├────────────────────────────────────┤
│ 3. 真实案例（2个）                 │
│    · 国内/国际案例结合             │
│    · 数据支撑 + 关键洞察           │
├────────────────────────────────────┤
│ 4. 应用方法                        │
│    · 决策框架/步骤                 │
│    · 常见误区表格                  │
├────────────────────────────────────┤
│ 5. 延伸思考 + 下期预告             │
└────────────────────────────────────┘
```

### 结构原则

| ✅ 保留 | ❌ 删除 |
|--------|--------|
| 引入案例 | ❌ 3分钟精华版开头 |
| 核心概念深入讲解 | ❌ 不同场景的思考框架 |
| **2个真实案例** | ❌ "如何训练XX思维"部分 |
| 应用方法（三步法/误区/清单） | ❌ 推荐阅读 |
| 延伸思考 |  |
| 下期预告（统一用"我们来聊聊"） |  |

## 十二、CommonMark 加粗语法规范

### 规则说明

CommonMark 规范要求 `**` 结束时，其右侧不能紧跟标点符号，否则解析器会认为这个 `**` 不是有效的结束标记。

**被视为标点的字符：**
- 全角括号：（）、【】、〔〕、［］、｛｝
- 全角引号："", '', 『』, 「」
- 全角顿号、句号、逗号、分号、冒号
- 其他全角标点符号

**正确示例：**
- ✅ `**文本**（解释）` - 加粗后有空格再接括号
- ✅ `**核心要点**是...` - 加粗后有空格再接文字
- ✅ `**文本**。` - 加粗后有空格再接句号

**错误示例：**
- ❌ `**文本**（` - 右括号紧跟 ** 导致解析失败
- ❌ `**文本**（` - 全角括号紧跟
- ❌ `**"文本"**` - 引号紧跟

### 解决方案

1. **加粗后加空格**：在 `**` 结束后加一个空格再接标点
2. **使用英文标点**：使用英文半角括号 () 代替全角括号（）
3. **调整语序**：将标点移到加粗内容之前

## 十三、固定格式汇总

### 必须使用的固定表达

| 位置 | 固定表达 |
|------|----------|
| 下期预告开头 | **下期预告：** 我们来探讨 |
| 案例数量 | 固定2个 |
| 案例洞察标题 | **关键洞察** 或 **启示** |
| 加粗格式 | `**文本**` 而非 `**"文本"**` |
| CommonMark 加粗 | ** 结束右侧不能紧跟标点符号，如 `**文本**（` 而非 `**文本**（` |
| 核心概念章节 | 直接以小段标题开始，不用"核心概念："前缀 |

### 标题格式规范（2025年1月31日更新）

| 位置 | 格式 | 禁止使用 |
|------|------|----------|
| 案例章节标题 | `## [主题]如何影响决策` | `## 真实案例：...` |
| 子案例标题 | `### [案例标题]` | `### 案例一：...`、`### 案例二：...` |
| 应用部分标题 | `## 如何用[思维]改善决策？` | `## 如何应用这个原理`、`## 如何在工作和生活中应用这个原理` |

**禁止使用任何固定的章节前缀或标记用语，包括但不限于：**
- ❌ "案例一"、"案例二"、"案例三" 等编号
- ❌ "真实案例：" 前缀
- ❌ "以下案例说明..." 等引导语
- ❌ "核心概念：" 前缀
- ❌ "概念讲解：" 前缀
- ✅ 只需使用简洁的内容标题即可（如直接使用 `## 什么是边际思维？`）
