## 自动化流程

```
┌──────────────────────────────────────────────────────────────┐
│                     文章发布自动化流程                         │
├──────────────────────────────────────────────────────────────┤
│                                                              │
│  1. 选择文章                            │
│     └── 支持序号或文件名匹配                                │
│                                                              │
│  2. 提取 Mermaid 图表                │
│     └── 正则匹配 ```mermaid...``` 代码块                   │
│                                                              │
│  3. 转换为在线 URL                       │
│     └── 使用 mermaid.ink 服务，Base64 编码               │
│                                                              │
│  4. 替换文章内容                               │
│     └── 将 Mermaid 代码块替换为 <!-- 原图缺失: URL -->              │
│                                                              │
│  5. 分析文章主题                            │
│     └── 根据关键词自动识别: decision/efficiency/strategy...  │
│                                                              │
│  6. 生成封面配图 (AI)                        │
│     └── 通义万相（阿里云）：新用户免费 50 张              │
│     └── 智谱 CogView4：API 调用                          │
│     └── 失败时自动降级到 Unsplash 备用图库                │
│                                                              │
│  7. 添加 Frontmatter                          │
│     └── title: 文章标题                                    │
│     └── cover: 封面图片 URL                                │
│                                                              │
│  8. 保存发布版                       │
│     └── 文件名: {原文件名}-发布.md                        │
│                                                              │
│  9. 发布到微信草稿箱                     │
│     └── 调用文颜 CLI: wenyan publish                      │
│                                                              │
└──────────────────────────────────────────────────────────────┘
```

## 快速开始

### 1. 获取 AI 生图 API Key

#### 通义万相（推荐）
1. 访问 [阿里云百炼控制台](https://bailian.console.aliyun.com/)
2. 开通服务（新用户免费 50 张图片）
3. 创建 API Key
4. 复制到 `.env` 文件的 `WANXIANG_API_KEY`

#### 智谱 CogView4（可选）
1. 访问 [智谱开放平台](https://open.bigmodel.cn/)
2. 注册/登录账号
3. 创建 API Key
4. 复制到 `.env` 文件的 `ZHIPU_API_KEY`

### 2. 配置环境变量

编辑 `.env` 文件：

```env
# 微信公众号配置
WECHAT_APP_ID=wx071b095c78095bc4
WECHAT_APP_SECRET=0e560908dcd91d9cddcc3b0ec0cf722c

# AI 生图服务配置
WANXIANG_API_KEY=sk-your-wanxiang-key-here
AI_PROVIDER=wanxiang
```

### 3. 运行发布脚本

```bash
# 发布第1篇文章（含 AI 封面）
node scripts/publish.js 01

# 预览模式（不实际发布）
node scripts/publish.js 01 --dry-run

# 使用自定义封面
node scripts/publish.js 01 --cover "https://example.com/cover.jpg"

# 跳过 AI 生成
node scripts/publish.js 01 --no-ai
```

### 主题识别

脚本会根据文章内容自动识别主题：

| 主题 | 关键词 | 提示词风格 |
|------|--------|-----------|
| decision | 机会成本、选择、决策 | 决策路口概念 |
| efficiency | 边际、效率、996 | 效率优化概念 |
| incentive | 激励、KPI、绩效 | 团队协作概念 |
| economics | 价格、供需、市场 | 经济金融概念 |
| strategy | 博弈、策略、竞争 | 战略规划概念 |
| behavior | 心理、行为、偏差 | 行为心理概念 |
| cooperation | 分工、协作、比较优势 | 合作共赢概念 |
| innovation | 创新、技术、变革 | 创新变革概念 |
| business | 默认 | 通用商务概念 |

## 图表转换说明

### 支持的图表类型
- 流程图 (`graph` / `flowchart`)
- 序列图 (`sequenceDiagram`)
- 类图 (`classDiagram`)
- 状态图 (`stateDiagram`)
- 实体关系图 (`erDiagram`)
- 甘特图 (`gantt`)
- 饼图 (`pie`)
- 其他 Mermaid 支持的类型

### URL 生成规则
```
原始代码:
```mermaid
graph LR
  A --> B
```

转换后 URL:
https://mermaid.ink/img/Z3JhcGggTFJBIC0tPiBC?type=png
```

### URL 特点
- ✅ 永久有效
- ✅ 支持 PNG/SVG 格式
- ✅ 无需额外存储
- ✅ 可直接嵌入 Markdown

## 发布到微信

发布版文件会通过文颜 CLI 发送到微信公众号草稿箱：

```bash
wenyan publish -f "articles/01-xxx-发布.md"
```

发布后需要：
1. 登录微信公众号后台
2. 进入草稿箱
3. 检查文章格式
4. 手动编辑并正式发布

## 故障排除

### AI 图片生成失败

**问题：** `401 Unauthorized`
- **解决：** 检查 API Key 是否正确

**问题：** `ECONNREFUSED`
- **解决：** 检查网络连接

**问题：** `通义万相返回格式异常`
- **解决：** API 可能返回了错误信息，会自动降级到 Unsplash

### 图表无法显示
- 检查 Mermaid 语法是否正确
- 确认 mermaid.ink 服务可访问
- 尝试在浏览器中直接访问生成的 URL

### 发布失败
- 确认 `.env` 文件配置正确
- 检查 `wenyan` CLI 是否已安装
- 确认微信 AppID/AppSecret 有效

## 常见问题

### Q: 如何批量发布所有文章？
A: 目前需要逐篇发布，批量功能计划中。

### Q: AI 生成的图片可以商用吗？
